# codex-pets-roa

Custom desktop pet "Roa" for [Codex Pets](https://github.com/PierroX4/codex-pets).

![Run Cycle](run_cycle_perfect.gif)
![Idle Sway](idle_sway_perfect.gif)

## Installation

Download `roa.codex-pet` from the [Releases](https://github.com/seanoon/codex-pets-roa/releases) page and import it into Codex Pets.

## Build from Source

Requirements:
- Python 3.9+
- Pillow (`pip install Pillow`)

Build the package:

```bash
python build.py
```

This will generate:
- `roa.codex-pet` (package bundle)
- `roa_pet/spritesheet.webp`
- `roa_pet/spritesheet_preview.png`
- Preview GIFs
